# NANDA Town site

Static landing site for [NANDA Town](https://github.com/projnanda/nandatown), the open-source proving ground for agent protocols.

Live at https://dhve.github.io/nandatown-site/

Single self-contained `index.html`, no build step. Design language: Neue Haas Grotesk, brand yellow `#F2C400`, dotted grid, JetBrains Mono for terminal and code.
